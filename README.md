# 🎓 Arya - Official AI Assistant for Chanakya University

**Arya** is an interactive, responsive, and intelligent AI Web Chatbot designed specifically for **Chanakya University**, Bengaluru. It assists prospective students, parents, and visitors with accurate information regarding admissions, course offerings, fee structures, scholarships, campus facilities, hostels, placements, and contact details.

---

## 🌟 Key Features

- **Warm & Student-Friendly Conversational Engine**: Designed with Arya's official persona guidelines and fallback rules.
- **Instant Quick-Query Chips**: Fast navigation for popular topics (Admissions, Courses, Scholarships, Hostels, Placements, Campus Visit, etc.).
- **Interactive Action Modals**:
  - 📝 **Apply Now 2026**: Directly submit application inquiries for various degree programs.
  - 📞 **Request Callback**: Schedule an instant callback from admissions counselors.
  - 🏛️ **Schedule Campus Visit**: Book guided campus tours for Chanakya University's 100+ acre Devanahalli campus.
- **Custom Design System**:
  - Royal Navy (`#0F2C59`) & Gold (`#D4AF37`) palette representing Chanakya University.
  - Seamless Light/Dark Mode toggle.
  - Smooth micro-interactions and glassmorphism UI elements.

## 🚀 How to Run the Project

You can run Arya locally using any static web server. Follow any of the methods below:

### Method 1: Using Node.js / `npx` (Recommended)

1. Open your terminal / command prompt.
2. Navigate to the project directory:
   ```bash
   cd c:\Education\Chatbot
   ```
3. Run `http-server` using `npx`:
   ```bash
   npx http-server -p 8080
   ```
4. Open your browser and navigate to:
   ```
   http://localhost:8080
   ```

---

### Method 2: Using Python Built-In HTTP Server

If you have Python installed on your system:

1. Open your terminal:
   ```bash
   cd c:\Education\Chatbot
   ```
2. Start Python's HTTP server:
   ```bash
   python -m http.server 8080
   ```
3. Open your browser at:
   ```
   http://localhost:8080
   ```

---

### Method 3: Direct File Opening or VS Code Live Server

- **Direct Open**: Double-click `index.html` to open directly in any modern browser (Chrome, Edge, Firefox, Safari).
- **VS Code**: Install the **Live Server** extension, right-click `index.html`, and select **Open with Live Server**.
